# Slap Battles Effect Values

Value list and Win/Fair/Lose calculator for Slap Battles hit and spawn effects. The values are worked out from
real trades in the official Slap Battles Discord (#trading and #high-trading).

**Live site:** https://YOUR-USERNAME.github.io/slap-battles-values/

## Updating values
Edit `values.json` (on GitHub: open the file → pencil icon → edit → Commit). The site picks up the change
in about a minute. Each effect has `value`, `demand` (high/mid/low), `confidence`, and optional `aliases`
(nicknames the search understands).

The Discord bot uses the same `values.json` format, so you can copy the file between the two.
